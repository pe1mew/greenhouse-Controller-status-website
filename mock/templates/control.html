Mode

mode.flags (toggle to add / remove from payload)

Flags map to badges in the dashboard's Mode tile. Red = alarm, yellow = warn, blue = info. Sixteen known strings (contract 2.0, fw up to 2.14.0) plus the client-side synthetic sd_not_mounted derived from system.sd_mounted. The four flags wind_override, calibrating, motor_alarm, and standby are auto-suppressed when the matching mode pill is already showing (WIND_OVERRIDE, WINDOW_CAL, MOTOR_ALARM, STANDBY) — the state surfaces once. net_backoff_active is defined in the contract but not yet emitted by the firmware (breaker not wired as of 2.14.0). The __unknown__ button verifies TR-48 (unknown flags must silently drop, no console error).
